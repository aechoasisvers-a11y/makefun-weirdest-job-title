## Entry

The program writes one job title — the weirdest it can think of, 60 characters
or fewer and nothing else — to `/output/entry.txt`:

> Vice President of Apologizing to Geese

## Run

```sh
python3 main.py
```

Pure stdlib Python 3.13, deterministic output. The program asserts the entry
sits inside the 1–60 character gate and verifies the written bytes match the
intended text before exiting.
